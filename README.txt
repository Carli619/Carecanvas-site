CareCanvas website files

Files:
- index.html: responsive, clickable CareCanvas prototype
- manifest.json: installable web app metadata

Publish it using GitHub Pages:
1. Sign in or create an account at https://github.com
2. Create a new public repository named carecanvas-site.
3. Upload index.html and manifest.json to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub to provide the site URL.
7. Open that URL in Safari on your iPhone → Share → Add to Home Screen.
8. Name the icon CareCanvas.

Important: this is a fictional interface prototype. It is not connected to Scripps or any healthcare provider. All lab results and other records are sample placeholders and must not be represented as real test results.
